# Contribuer à OSEF AI Engineering
1. Ouvrir une issue décrivant le besoin, les sources et les critères d'acceptation.
2. Créer une branche dédiée, proposer une PR limitée et documentée.
3. Fournir instructions de reproduction, tests, versions, licences et résultats mesurés.
4. Respecter les mainteneurs, la confidentialité, les droits de propriété intellectuelle et les politiques de divulgation responsable.
5. Ne jamais commiter de secrets, de données personnelles ou de données commerciales confidentielles.

Le dépôt étant public, les contenus destinés aux clients doivent être anonymisés et approuvés.
