# OSEF AI Watch — veille journalière

## Axes suivis
1. Modèles : nouveautés, poids, code, licences et OSAID.
2. Data : datasets, RAG, gouvernance, qualité, provenance.
3. Infrastructure : GPU, CPU, cloud providers, Kubernetes, inference.
4. Platforms : MLOps, LLMOps, serving et observabilité.
5. Security : vulnérabilités, sécurité des agents, conformité.
6. Business : prix, partenariats, AI-as-a-Service, marchés.
7. Africa : acteurs, langues, communautés et infrastructures africaines.

## Critères de publication
Chaque fiche datée contient : source primaire et lien, date de l'annonce **et** de publication si différentes, faits vérifiés, catégorie (open weights / open source AI, etc.), impact DSI africaines, action OSEF, statut (à vérifier / vérifié / archivé). Ne pas inventer d'annonce ou de benchmark.

Conserver ici des synthèses validées de la veille ; la tâche planifiée ChatGPT **ne pousse pas automatiquement** vers GitHub. Un workflow explicite et ses permissions seront nécessaires pour toute synchronisation.
