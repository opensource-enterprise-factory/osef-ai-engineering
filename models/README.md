# Open Models — taxonomie
**Open Weights ≠ Open Source AI**. « Open Models » est une expression générique.

Étudier par version : licence, droits d'utilisation/modification/redistribution, disponibilité des poids, code d'entraînement et d'inférence, informations sur données et provenance, restrictions commerciales, dépendances matérielles, résultats reproductibles.

Référence normative : [OSI Open Source AI Definition 1.0](https://opensource.org/ai/open-source-ai-definition). Ne pas attribuer de conformité OSAID sans vérification documentaire complète.
